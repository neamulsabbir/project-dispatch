# Project Runner

খোলা VS Code বা Cursor উইন্ডোগুলো থেকে প্রজেক্টের লিস্ট দেখায়। যেগুলো সিলেক্ট করবে, সেগুলোর নিজ নিজ টার্মিনালে একসাথে কমান্ড চলে।

`package.json` এ `dev`, `start`, বা `serve` স্ক্রিপ্ট থাকলে সেটা নিজে থেকে বসে। লকফাইল দেখে yarn, pnpm, npm, বা bun বেছে নেয়। প্রজেক্ট আলাদা কমান্ড চাইলে রোতে লিখে রাখা যায় — সেটা সেভ হয়ে থাকে।

## কীভাবে চালু করবে

1. Cursor এ `G:\project-runner` ফোল্ডারটা খোলো।
2. `npm install` তারপর `npm run package`।
3. Command Palette থেকে **Extensions: Install from VSIX...** চালিয়ে তৈরি হওয়া `.vsix` ফাইলটা ইনস্টল করো।
4. উইন্ডো রিলোড করো।

অ্যাকটিভিটি বারে Project Runner আইকনে ক্লিক করলে প্রজেক্ট লিস্ট আসবে। অন্য উইন্ডোতে ফোল্ডার খোলা থাকলে কয়েক সেকেন্ডের মধ্যে সেগুলোও এই লিস্টে চলে আসে।

ডিবাগ করতে চাইলে এই ফোল্ডারে F5 চাপো। সেটা শুধু Extension Development Host উইন্ডোতে চলে। আসল প্রজেক্ট উইন্ডোগুলোতে একসাথে চালাতে VSIX ইনস্টল করতে হবে।

## Run status

প্রতিটা প্রজেক্টের পাশে লাইভ স্ট্যাটাস দেখায়: `starting`, `running`, `done`, `error`, বা `stopped`। Shell integration থাকলে exit code দিয়ে success/error ধরা হয়। টার্মিনাল বন্ধ করলে `stopped` হয়।

## Split terminals

একই উইন্ডোতে একাধিক প্রজেক্ট Run করলে টার্মিনালগুলো পাশাপাশি split হয়ে খোলে। বন্ধ করতে Settings এ `projectRunner.splitTerminals` অফ করো।

## যেভাবে কাজ করে

একটা উইন্ডো অন্য উইন্ডোর টার্মিনাল সরাসরি ধরতে পারে না। তাই এক্সটেনশন প্রতিটা উইন্ডোতে চালু থাকে এবং নিজের ফোল্ডারের নাম `%USERPROFILE%\.project-runner` এ লিখে রাখে। Run চাপলে অন্য উইন্ডোর এক্সটেনশন সেই কমান্ড নিজের টার্মিনালে চালায়। টার্মিনালের নাম হয় `Project Runner · folder-name`। আবার Run চাপলে আগের সেই টার্মিনাল বন্ধ হয়ে নতুন করে কমান্ড শুরু হয়।
